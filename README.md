## 📌 Project Overview

**TempFlow** is an interactive web-based temperature conversion application developed for the **TAE-1 Project Based Learning (PBL)** practical.

### Assigned Topic

> **"Build a real-time conversion tool supporting Celsius, Fahrenheit, and Kelvin temperature scales."**

The application allows users to enter a temperature and select its input scale. The equivalent values in **Celsius, Fahrenheit, and Kelvin** are calculated and displayed instantly.

The project is designed as a simple, functional, responsive and attractive frontend application that can be deployed using **GitHub Pages**.

---

## 🎯 Objectives

- To develop a real-time temperature conversion tool.
- To convert temperatures between Celsius, Fahrenheit and Kelvin.
- To implement conversion logic using JavaScript.
- To design an attractive responsive interface using HTML and Tailwind CSS.
- To provide instant conversion results.
- To validate user input.
- To handle temperatures below absolute zero.
- To maintain the project source code using GitHub.
- To deploy the application using GitHub Pages.

## 🛠️ Technologies Used

### HTML5

HTML5 is used to create the structure of the application, including:

- Header
- Input field
- Temperature scale selector
- Result cards
- Buttons
- Footer

### Tailwind CSS

Tailwind CSS is used for the visual design and responsive layout.

It provides:

- Responsive grid layouts
- Spacing
- Typography
- Borders
- Rounded cards
- Gradients
- Hover effects
- Responsive design
- Modern glass-style interface

Tailwind CSS is included using its CDN.

### JavaScript

JavaScript is used to implement the complete conversion functionality.

It handles:

- User input
- Temperature calculations
- Scale selection
- Real-time updates
- Validation
- Error messages
- Reset functionality
